文書の一覧

行のクリック＝対象の選択（複数可）。文書の中を直すときだけ行末の「開く」

    やることは3つ

    1. ヒットを確認（上の青いボタン）— 生成AI関連語のヒットを1件ずつ、原本と前後の文脈を見て ✓（Enterでも進めます）。目次・ページ番号などが混ざっていたら、その場で理由を選んで外す
    2. ぜんぶ ✓ になったら、確認モード右上の全冊書き出し → KHCoder_抽出単位.xlsx（年・企業・群での分割も選べます）
    3. KH Coder：新規プロジェクト → 列「テキスト」→ 強制抽出語 → 前処理 → 共起ネットワーク（集計単位 H5）

    出現率（冊ごとのヒット文数・総文数と率＝RQ1の材料）は上の出現率ボタンから。
    前処理は柱（全ページで反復する文言）の除去だけ＝冊ごとの判断はありません。 手作業はすべて設定JSONに残り、同じ入力から同じ出力が再現されます（卒論の再現性と監査の材料）。

    新しいPDFを追加

    ファイル名は 企業名_年度.pdf に揃えて保存します。この名前がそのまま KH Coder の外部変数（企業名・年度）になります。

    確認モード
    100%

    1柱（反復する文言）を落とす

    全ページのこの割合以上で「同じ位置に同じ文言」が出る行を柱（ナビ・ランニングヘッド・タイトル入りフッター）として落とします（0 で無効）。 落とした行は赤い破線で出ます。これが唯一の「捨てる」規則です （ヘッダー・フッターの座標カットは 2026-08-31 に廃止。反復しない番号・章名が ヒットに混ざったときは、確認モードで「ヘッダー／フッターのため除外」を選びます）。

    2本文の文字サイズ

    文書全体でいちばん文字数の多いサイズを本文とみなします。緑が本文の範囲。図表の多い会社でキャプションが最多になるときだけ手で上書きします。
    TINY_RATIO：本文より極端に小さい文字を種別「極小」にします（0 で無効）。消してはいません。

    3行の繋ぎ方

    JOIN_GAP：横に割れた行を繋ぐ隙間の上限（文字サイズ比）。上げすぎると2段組みの左右が繋がります。 COL_TOL：上げると別の列が繋がり、下げると同じ段落が割れます。LINE_GAP：上げると離れた行まで繋がります。 右の一覧とページ上の枠はホバーで連動します。

    4続く文と表

    数える単位は文とページです（段落は作りません）。 続く文を繋ぐ：句点で終わらず最終行が右端まで届いているブロックを次のブロックに繋ぎます。 表：罫線で区切られた表を 1行＝1ブロック に組み直します。図解の枠線を表と誤認したページは右の一覧の上で検出を切れます。

    5ページ一覧

    クリックでそのページへ飛べます（下線＝表のあるページ）。 ページ除外は 2026-08-31 に廃止しました。分母は全ページ・全文で数えます。

    保存先 卒研データ\設定\企業名_年度.json

    画面の幅が足りないので、右の文の一覧を畳んでいます。

    検索語を含む文と、その前後N文を1つの窓にして一覧します（重なる窓は1つに）。
    初回は数秒〜数十秒かかります。窓をクリックするとそのページへ飛びます。

    検索語のヒット箇所を規則で単位化します：本文→その文 ／ 表→その行 ／ ラベル→その文（結合できる）／ 見出し→その行。
    薄い文をクリックすると単位に足せます。単位ごとに「外す」で理由を付けて除外できます。手作業はすべて設定JSONに残ります。
