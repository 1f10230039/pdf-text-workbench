# 0004. 集計単位を「文 × ページ」とし、段落の復元を行わない

- Status: Accepted

## Context

抽出したテキストをどの単位で区切るかは、後段の分析（頻度集計・共起）の結果を左右する。
自然な候補は「段落」だが、PDF には段落という構造情報が存在せず、
レイアウト（字下げ・空き行・ブロックの切れ目）から推定するしかない。

## Decision Drivers

- 全文書に同じ規則を適用できること（文書ごとに精度が揺れる単位は比較を壊す）
- 規則が説明可能であること
- 文書側のデザイン差（空き行を入れない組版・写真回り込みの狭い折り返し等）への頑健性

## Considered Options

1. **文 × ページ** — 文は句点で機械的に切れる。ページは PDF が構造として持っている。
   どちらも全文書で同じ規則が成立する
2. 段落の復元 — 字下げ・行送り・ブロック境界からの推定は、ある文書で合わせると
   別の文書で壊れる（段落の定義自体がデザイン依存で、レイアウト規則に還元できない）
3. 固定長ウィンドウ — 機械的だが、文の途中で切れて意味単位として使えない

## Decision

集計単位を「文 × ページ」とする。ブロックの切れ目は句点の補完位置（＝文の境界）としてだけ使い、
段落の復元は行わない。文と ページの中間の粒度が必要な分析には、
ヒット文の前後 N 文を束ねる**文脈窓**を補助として使う。

## Consequences

- (+) 単位の定義が全文書で同一・機械的になり、比較と再現が成立する
- (+) 段落推定のための文書ごとのチューニングが不要になる
- (−) 段落単位の分析はできない（文脈窓が部分的な代替）
- (−) 句点を使わないテキスト（表・ラベル）には句点を補う規則が別途必要
